# Работа №1 — алгоритмы и структуры данных

Простые учебные реализации на C++14. STL-контейнеры не используются.

## Задания

1. `task_01` — шифрование и дешифрование файлов алгоритмом RC4.
2. `task_02` — массив логических значений в `unsigned int`.
3. `task_03` — комплексное число.
4. `task_04` — матрица: арифметика, транспонирование, определитель, обратная матрица.
5. `task_05` — интерфейс приоритетной очереди.
6. `task_06` — двоичная куча.
7. `task_07` — биномиальная куча.
8. `task_08` — фибоначчиева куча.
9. `task_09` — левосторонняя куча.
10. `task_10` — косая куча.

Во всех очередях меньшее значение ключа означает более высокий приоритет.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Каждая папка содержит отдельную демонстрационную программу `main.cpp`.
Краткое объяснение алгоритмов и их сложности находится в `EXPLANATIONS.md`.
